A tiny chess engine in 4 KB of Python: a fork of Thomas Ahle's sunfish (piece-square tables, MTD search, transposition table) with a 50,000-node-per-move budget and a 7-second deadline safety net, built for make.fun's tiny-chess-01 bounty. Local gauntlet (trial-1): 6 wins out of 6 games.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
